题目单选题

设函数 z = z(x, y) 由方程 x − az = ey+az 确定，其中 a 是非零常数，则（　）。

A∂z/∂x − ∂z/∂y = 1/a正确答案
B∂z/∂x + ∂z/∂y = 1/a你的选择
解析与错因

两边分别对 x、y 求偏导后相减，含 ey+az 的项恰好抵消。错因：丢掉了 ∂z/∂y 的负号。
