题目单选题

设函数 z = z(x, y) 由方程 x − az = ey+az 确定，其中 a 是非零常数，则（　）。

A∂z∂x − ∂z∂y = 1a正确答案
B∂z∂x + ∂z∂y = 1a你的选择
C∂z∂x − ∂z∂y = −1a
D∂z∂x + ∂z∂y = −1a
解析与错因

两边分别对 x、y 求偏导后相减，含 ey+az 的项恰好抵消。错因：整理时丢掉了 ∂z/∂y 的负号，误写成相加。

为什么是相减不是相加？我选了 B。
分别对 x、y 求偏导并整理，两式相减时含 ey+az 的项刚好抵消，得到 zx − zy = 1/a，所以选 A。
