# 今知错题本 · 产品首页

纯静态单文件页面：`index.html`，不依赖任何框架、构建工具或外部资源（字体走系统字体栈，图标为内联 SVG），双击即可在浏览器打开，也可直接部署到任意静态托管。

## 上线前需要替换的占位内容

- **小程序码**：`index.html` 中搜索 `二维码占位`，把 `.qr` 里的 SVG 换成真实的小程序码图片（例如 `<img src="qrcode.png" alt="今知错题本小程序码">`）。
- **页脚链接**：帮助中心 / 意见反馈 / 联系我们 / 用户协议 / 隐私政策 目前是 `href="#"`，请换成真实地址。
- **样机里的示例题目**：手机样机中的题目、文件夹名、数量均为演示数据，可按需改成真实内容。

## 结构

- 导航栏（吸顶）→ 首屏（错题详情样机）→ 使用流程 → 六个功能展示区（整理 / 录入 / 追问 / 导图 / 复习 / 导出）→ 十项功能一览 → 适合谁 → 扫码使用 → 页脚
- 品牌蓝 `#376EFF`，语义色沿用小程序：绿 `#259D56`、红 `#E5484D`、橙 `#F18C32`、紫 `#7649D8`
- 「复习有方」区块的四个复习方式按钮可点击切换右侧演示卡片，进入视口后会自动轮播，点击后停止
