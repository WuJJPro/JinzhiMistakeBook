# 今知错题本 · 官网

纯静态页面，不依赖任何框架、构建工具或外部资源（字体走系统字体栈，图标为内联 SVG），双击即可在浏览器打开，也可直接部署到任意静态托管。

```
Website/
├── index.html            首页
├── download.html         下载页
├── assets/
│   ├── style.css         两个页面共享的样式（色板、按钮、导航、页脚）
│   ├── fonts.css         内嵌的子集字体（标题：Noto Serif SC 900；手写批注：Long Cang），自动生成
│   └── icon.png          App 图标（256px）
└── tools/
    └── subset-fonts.js   重新生成 fonts.css 的脚本
```

## 字体

标题用 Noto Serif SC 900，红笔批注用 Long Cang，两款都是 SIL OFL 1.1 授权。为了不依赖外网字体服务，`assets/fonts.css` 只包含页面实际用到的字符（约 190 + 35 个），以 data URI 内嵌。**改了标题或批注文案后**，重新生成一次：

```bash
npm i subset-font        # 首次
node tools/subset-fonts.js
```

## 首页结构

1. **首屏「一道错题的一生」**（深色）：一段约 20 秒的循环动画。鼠标在首屏移动时，试卷、手机、卡片会有轻微的 3D 视差。试卷上的红叉 → 手机拍照 → AI 逐字识别、补全答案与标签 → 归入文件夹树 → 出现在今日复习 → 红叉变绿勾、盖上「已学透」。下方的章节条可点击跳到任一步，「重播」从头播放。动画只在进入视口时运行，遵循系统的「减少动态效果」设置。
2. **六个场景**：左侧文案滚动，右侧手机固定并切换到对应界面（录入 / 整理 / 追问 / 导图 / 复习 / 导出），十项功能亮点分布在这六步里。
3. **功能一览**：答题卡样式的十项功能清单。
4. **多端可用**：iPhone / iPad、Android、Windows、Mac。
5. **下载入口** 与页脚（含 ICP 备案号）。

## 下载页

- 按访问设备自动推荐安装方式（iOS → App Store，Android → APK，Windows → exe，Mac → dmg），并高亮对应卡片。
- 四个平台卡片的链接与当前 jinzhi.fun 下载页一致；App Store 与 Android APK 卡片带真实可扫的二维码。

## 更新版本时

- 安装包链接与版本号在 `download.html` 中出现两处：卡片内的按钮，以及页面底部脚本里的 `links` 对象（用于自动推荐）。两处一起改。
- Android 二维码编码的是 APK 直链，换包后需要重新生成：`npx qrcode -t svg -o android.svg "<新的 APK 链接>"`，然后替换卡片里的 SVG。
